### The one backend failure

- **Test:** `ai_scribe/test_stt_languages.py::ProviderSelectionTests::test_service_rejects_unsupported_language`
- **Error:** `FileNotFoundError: …/hms-stt-test-xxxx/tmpxxxx.webm`
- **Root cause (test code, not product):** the module creates one shared temp dir `MEDIA = tempfile.mkdtemp(...)` (line 28). `WhisperApiClientTests.tearDownClass` (lines 88–90) `rmtree`s it, then `ProviderSelectionTests` (line 144+) calls `_audio_file()`, which writes into the deleted dir. Order-dependent; fails deterministically in a full run.
- **Category:** test-isolation bug. **Module:** AI scribe.
- **Fix:** give each class its own temp dir (`setUpClass`/`tearDownClass`), or have `_audio_file()` call `os.makedirs(MEDIA, exist_ok=True)`, or drop the `rmtree` from that one class and clean up once at module level.

### Warnings worth acting on
- `UnorderedObjectListWarning` on paginated querysets: `clinical.Allergy`, `encounters.Visit`, `ipd.DischargePlan`. Pagination can skip or duplicate rows. Add `ordering` to the model `Meta` or the viewset queryset.
- `datetime.utcnow()` deprecations in `interoperability/fhir/resources/base.py:55,268` and `mappings/diagnosticreport.py:107`.

### E2E specs that passed
`login.spec.js`, `opd-to-bill.spec.js` (register → doctor calls/sees/completes → billing raises bill and takes full payment), `ipd-bed.spec.js`. Server logs during E2E show expected 401s for pre-login directory fetches and a 404 on `/api/auth/dev/login/` (dev login is deliberately disabled in E2E settings).
